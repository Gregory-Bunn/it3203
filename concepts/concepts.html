Key Concepts

World Wide Web

The global information space where documents and other web resources are identified by URLs and linked by hypertext. The very first web browser also shared the name "WorldWideWeb" and was developed by Tim Berners-Lee at CERN in 1990."

Hypertext

A structural software system that links text, topics, and graphics on a screen to other related items. Tim Berners-Lee at CERN was one of the first to utilize it, hypertext forms the foundational framework for connecting independent web documents together via hyperlinks.

Document Object Model (DOM)

A structural model generated by a browser's rendering engine. When an HTML document is loaded, the engine constructs the DOM, a representation of the web page.

Just-In-Time (JIT) Compilation

An efficient code optimization technique used by JavaScript engines (such as Chrome's V8 or Firefox's SpiderMonkey). Instead of interpreting code line-by-line, JIT compiles JavaScript at runtime, allowing complex web applications to run at incredibly fast speeds.

Multi-Process Architecture

Modern browsers isolate individual tabs and extensions into separate processes. This ensures that if a single webpage crashes, the remaining browser tabs stay stable and responsive, while also maximizing multi-core processor performance.
